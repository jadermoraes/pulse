# Screenshots & demo assets

Drop image/GIF files here with the **exact names below** and they'll render in the main [`README.md`](../../README.md).

| File | What to capture | Suggested |
|---|---|---|
| `dashboard.png` | The full admin dashboard with a few widgets (server stats, requests, torrents, recently added). The hero shot. | ~1600px wide, dark theme |
| `assistant.png` | The AI assistant panel mid-conversation — ideally showing a **Confirm/Cancel** write card. | panel + one tool result |
| `consumer-app.png` | The `/app` consumer home on a phone frame (discover rows + ask-bar). | mobile width (~390px) |
| `cost.png` | The Token Usage modal — per-model rows with `$`, the window toggle, and the spend-limits editor. | the modal only |

**Tips**
- Use the dark theme for consistency with the badges/hero.
- Crop tightly; avoid the browser chrome where possible.
- For the GIF, [`peek`](https://github.com/phw/peek) or macOS screen-record → [gifski](https://gif.ski/) keeps it small.
- Optional extras the README would happily take: `messages.png` (admin inbox), `services.png` (the launcher with real logos), `roles.png` (Users & Roles).
